# Modelo detallado del SIIF Nación (Colombia)

Modelo documental completo del **Sistema Integrado de Información Financiera – SIIF Nación** del Ministerio de Hacienda y Crédito Público de Colombia, construido a partir de la página oficial de MinHacienda, sus instructivos y guías oficiales, con verificación cruzada de fuentes.

**Empieza por aquí → [00-modelo-general.md](00-modelo-general.md)** (síntesis con mapa de módulos, cadena presupuestal, perfiles, ciclo anual, interoperabilidad y normativa).

## Estructura de cada capítulo

Cada capítulo contiene: **Resumen** ejecutivo · **Detalle** (funcionalidades, transacciones con rutas de menú, flujos paso a paso, reglas de negocio) · **Roles y perfiles** · **Normatividad** · **Hallazgos clave** · **Documentos e instructivos oficiales** con enlaces.

> ⚠️ El SIIF Nación se actualiza continuamente mediante circulares externas del Administrador SIIF. Este modelo refleja la documentación pública disponible a julio de 2026; para operar, consulta siempre la circular vigente en [minhacienda.gov.co/siif](https://www.minhacienda.gov.co/siif).
