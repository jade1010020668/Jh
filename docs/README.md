# Proyecto "Amara" — Plataforma de Compañeras IA · Paquete de Planeación

Planeación completa para una plataforma web 18+ de compañeras IA (chat, voz, fotos y videollamada en tiempo real con avatar animado), con fase 2 de marketplace de creadoras reales y clones IA licenciados.

> **Estado**: planeación inicial · **Fecha**: julio 2026 · **Mercado inicial**: LATAM + global (ES/EN)
